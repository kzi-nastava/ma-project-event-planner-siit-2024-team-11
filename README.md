It is currently being developed in **Android Studio** and is intended for use on minimum **Android 11 (API level 30)** devices.

# Manual
Step by step guide on how to boot up the application without getting any errors

1) Download and run the backend part of this application [here](https://github.com/kzi-nastava/iss-project-event-planner-siit-2024-team-11)
2) Find out what your IPv4 address is (on Windows this can be done by opening the command prompt and using the command ipconfig)
3) Open the project in Android Studio and locate the local.properties file
4) Add the ip_addr parameter with your IP address (ip_addr=yourIpAddressHere)
5) Run the project with an emulator or on your Android phone
    - If you are running the project on your phone, you must ensure the device running the backend and your phone are connected to the same network
